# Settlement Placement Advisor Resources

## Knowledge

- [BepInEx dev guide: Patching methods during runtime](https://docs.bepinex.dev/articles/dev_guide/runtime_patching.html)
  Official BepInEx docs on HarmonyX patching: attributes, TargetMethod, postfixes. Use for: any patch work.
- [Harmony 2 documentation (pardeike)](https://harmony.pardeike.net/)
  Canonical Harmony docs: PatchAll, patch types, injection parameters (`__instance`, `__result`). Use for: patch
  mechanics.
- [Harmony: Class AccessTools](https://harmony.pardeike.net/api/HarmonyLib.AccessTools.html)
  Harmony's own reflection helpers: patch targets and injection parameters. Use for: patch work.
- [HUMANKIND Official Modding Guide (PDF)](https://medias.games2gether.com/universes/humankind/mods/HUMANKIND_Official_Modding_Guide.pdf)
  Publisher/developer modding guide: mod types, tooling, what the game supports officially. Use for: game-specific mod
  context.
- Local: the contract comments in the module sources (`pipeline/`, `gameapi/`, `presentation/`, `composition/`)
  The behavior contract: the rules the code implements, the seams, and the performance bound, stated on the class they
  govern. Use for: what a rule must do.
- Local: `GLOSSARY.md` (repo)
  Canonical module and domain vocabulary. Use for: naming things consistently in lessons and changes.
- Local: `reference/` decompiles, regenerated by `scripts/decompile-game.sh`
  Full decompiles of the game assemblies, the simulation assembly, and the Unity presentation assembly.
  Use for: vanilla behavior facts, UI/cursor/pins facts.
- Local: named decompiled anchors (`reference/`, paths relative to it)
  Per-fact anchors for vanilla-behavior checks:
  - `managed/firstpass/Amplitude.Mercury.Interop/SettlementPlacementCursorSnapshot.cs` - the snapshot sync the advisor
    answers (`EvaluatePlacement`).
  - `outgame/assembly-csharp/Amplitude.Mercury.UI/SettlementPlacementPinsSubset.cs` - the pin gate
    (`PinMustMeShown`).
  - `outgame/assembly-csharp/Amplitude.Mercury.UI/PlacementPinsSubset.cs` - the vanilla pin quota
    (`NumberOfRecommandedPins = 3`) and `FimsTier` flags.
  - `outgame/assembly-csharp/Amplitude.Mercury.Presentation/SettlementPlacementCursor.cs` - the placement cursor,
    `DeactivateCursor` (the smoke-check deactivation).
  - `outgame/assembly-csharp/Amplitude.Mercury.Presentation/TileFeedbackContainer.cs` - tile-feedback rendering
    (`StartFeedback`), the white-hex mechanism.
  - `managed/firstpass/Amplitude.Mercury.Interop/DistrictPlacementEvaluation.cs` and
    `CampPlacementEvaluation.cs` - the evaluation `ValidTiles` array and its `ValidTile` entry shape.

## Tooling

- [Conventional Commits specification](https://www.conventionalcommits.org/en/v1.0.0/)
  Canonical format spec implemented by CONTRIBUTING.md and `scripts/hooks/commit-msg`. Use for: commit message
  questions.
- [git-cliff](https://git-cliff.org/) (install: `cargo install git-cliff`)
  Generates GitHub Release notes from commit messages at tag time (`cliff.toml`). Use for: releases.
- [MinVer](https://github.com/adamralph/minver)
  Derives the assembly version from git tags; untagged builds report `1.0.0-alpha.0.<n>`. Use for: version questions.
